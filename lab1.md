# Веб-приложение "Случайный выборщик для повторения"

## Общее описание

Система предназначена для помощи студентам в планировании учебной сессии. Когда ученик не может определиться, какую тему ему повторить, приложение случайным образом выбирает одну из заранее добавленных в список. 

## Основной положительный сценарий

1. Пользователь заходит в приложение и видит свой список тем для повторения.
2. Пользователь нажимает кнопку "Выбрать случайную тему".
3. Система случайным образом выбирает одну тему из списка.
4. Система отображает выбранную тему крупным и заметным шрифтом.
5. Пользователь приступает к повторению выбранной темы.
6. После завершения пользователь может снова нажать кнопку, чтобы выбрать следующую тему.

## Альтернативные сценарии

### Список тем пуст
- При нажатии на кнопку "Выбрать случайную тему" система показывает сообщение "Ваш список тем пуст. Добавьте темы для повторения."

### Пользователь удалил все темы
- Система показывает сообщение "Тем не найдено" и кнопку "Добавить первую тему".

---

## Пользовательские истории


### Вход в систему

Я, как Пользователь, хочу входить в систему, чтобы получить доступ к своему персональному списку тем.

Основной сценарий:
1. Пользователь открывает приложение и видит форму входа
2. Пользователь вводит свой логин и пароль и нажимает кнопку "Войти"
3. Система проверяет данные и открывает главный экран приложения со списком тем

Альтернативные сценарии:
- Пользователь вводит неверный логин или пароль. Система показывает сообщение об ошибке "Неверный логин или пароль"


### Добавление темы для повторения

Я, как Пользователь, хочу добавлять новые темы в общий список, чтобы в дальнейшем приложение могло их случайно выбирать.

Основной сценарий:
1. Пользователь находится на главном экране и нажимает кнопку "Добавить тему"
2. Система открывает поле для ввода текста
3. Пользователь вводит название темы и нажимает "Сохранить"
4. Система добавляет тему в общий список и обновляет его отображение

Альтернативные сценарии:
- Пользователь пытается добавить пустую тему. Система не добавляет её и показывает сообщение "Название темы не может быть пустым"


### Случайный выбор темы

Я, как Пользователь, хочу нажать одну кнопку, чтобы система выбрала для меня случайную тему из списка.

Основной сценарий:
1. Пользователь находится на главном экране и видит кнопку "Выбрать случайную тему"
2. Пользователь нажимает кнопку
3. Система случайным образом выбирает одну тему из списка
4. Система анимированно выделяет выбранную тему на экране (например, увеличивает шрифт, подсвечивает фон)


### Управление списком тем

Я, как Пользователь, хочу иметь возможность просматривать, редактировать и удалять темы из списка, чтобы поддерживать его в актуальном состоянии.

Основной сценарий:
1. Пользователь видит весь список своих тем на главном экране
2. Пользователь нажимает на значок "редактировать" рядом с темой
3. Система позволяет изменить текст темы
4. Пользователь нажимает на значок "удалить" рядом с темой
5. Система удаляет тему из списка после подтверждения


### Повторный выбор темы

Я, как Пользователь, который уже повторил одну тему, хочу сразу же получить следующую случайную тему, чтобы продолжить эффективную подготовку.

Основной сценарий:
1. После того как система показала одну случайную тему, пользователь нажимает кнопку "Следующая тема"
2. Система сразу же выбирает и показывает новую случайную тему из оставшихся в списке
3. Пользователь может продолжать таким образом, пока не закончатся темы или не надоест

Альтернативные сценарии:
- В списке осталась только одна тема. Система показывает её с сообщением "Это последняя тема в вашем списке"
